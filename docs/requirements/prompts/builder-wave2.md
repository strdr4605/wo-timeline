## What to build

1. **The sample data** exactly as `docs/requirements/SAMPLE-DATA.md` states it, in the document
   structure of the brief: `{ docId, docType, data }`. Work centres in `docType: 'workCenter'`,
   work orders in `docType: 'workOrder'`. Put it in `src/app/data/sample-data.ts`. F1, F2, F3.
2. **A data service** that holds the work centres and the work orders, and a **pure overlap
   function** in that service or in a sibling file:
   `overlaps(candidate, existingOrders): boolean`, where `candidate` is a work order with
   `workCenterId`, `startDate`, `endDate`. Two orders overlap when they sit on the same work
   centre and their date ranges touch. The function must not depend on Angular, so a plain vitest
   test can call it. F4.
3. **The bars.** One bar per work order, inside the row of its work centre, in the timeline area
   of the grid.
   - Position: the same rule the current month marker uses. The bar starts at the interpolated
     position of the start date and ends at the interpolated position of the end date, inside the
     column that holds the date. Use the `--col-index` and `--col-fraction` custom properties of
     the grid, or compute the same way the marker does.
   - Bar height 38, radius 8, 1px border. Fill and border per status from the token file
     (`colors.status.*`).
   - The bar shows the work order name and a status badge. Badge height 22, radius 5, padding 8
     to the left, gap 8 to the bar end. Badge fill and text per status.
   - The bar text is the work order name, 14 Book, with 8px padding to the left.
4. **The three-dot actions button** on the bar. It appears on hover of the bar, it opens a menu
   with **Edit** and **Delete**. The menu is the design menu: width 200, radius 5, rows 28 high,
   padding 12, shadow y 4.5 blur 5 `#d8dceb`. It is not a system menu. C5, C6.
   - Edit and Delete do nothing yet. The drawer is the next wave. The menu must open and close.
5. **The hover tooltip** on the bar: name, status and the full date range. Height 26, radius 8,
   padding 8, background `#687196`, text `#f9faff`. C7.
6. **The drag handles** at both ends of the bar, visible on hover, as the design shows them. The
   handles appear; they do not resize yet. C8.
