## Date to pixel mapping (locked decision)

Columns have a **fixed width per column**. Inside a column, the position of a day is interpolated by
the fraction of the month, the week or the day that has passed. The header shows the label of the
column. The current month gets the pill marker in the header and the tinted column.

- Month view: one column per calendar month, label `Mon YYYY` (for example `Nov 2026`), width 114.
- Week view: one column per calendar week, label = the week start date, width 114.
- Day view: one column per day, label = the day number, width 48.
